Health

Three-layer health check per node (ping → DNS → Pi-hole API), with auto-heal escalation for a node that stays down: an SSH reboot after a few consecutive failures, then up to two more retries spaced several minutes apart — gated on cluster quorum so this never fires while the cluster itself may be unhealthy. If retries are exhausted the node is left down and flagged for manual intervention.
