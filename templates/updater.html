Updater

Checks each Pi-hole's software version and can upgrade it (pihole -up, then reboots). One node is auto-upgraded per day on a rotating schedule; you can also trigger any node manually below.

Nodes
Gravity (blocklist) updates

A blocklist URL that's briefly unreachable can be silently skipped/cached rather than erroring, with no reliable success signal from Pi-hole beyond "the command exited 0". One node updates gravity per day on its own rotating schedule (offset from the software updater's, so they don't collide); after each update, this compares the node's own blocklist domain count against its count before the update — a large drop is flagged as a probable partial-update failure rather than assumed to be a smaller but successful blocklist.
